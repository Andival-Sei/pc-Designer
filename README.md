# Next Rig

Личное пространство для планирования обновления ПК и телефона. Тёмная тема по умолчанию, сравнение «сейчас / хочу», цены в армянских драмах и сохранение без регистрации.

## Возможности

- ПК: CPU, GPU, материнская плата, RAM, накопитель, охлаждение, блок питания, корпус.
- Телефоны: текущая и желаемая модель, заметки, цена и ссылка.
- Живые предложения армянских магазинов: Mtech для комплектующих, iSpace для iPhone.
- Любые другие модели и магазины можно добавить вручную.
- Бюджет считает **только новое оборудование из колонки «Хочу»**.
- Автосохранение в localStorage, несколько проектов, импорт/экспорт JSON.
- Обмен снимком проекта через ссылку, адаптивный интерфейс и переключение темы.

## Локальный запуск (Windows 11)

Нужен Node.js 24+.

```powershell
npm ci
npm run dev
```

Vite обслуживает и интерфейс, и локальный `/api/catalog`. Ключи доступа и база данных не нужны.

```powershell
npm run build
npm run lint
npm test
npm run test:e2e
```

Браузерные тесты используют установленный Google Chrome. `npm run preview` показывает только статическую сборку; для API используйте dev-сервер или Vercel.

## Цены и ограничения

Сервер запрашивает только заранее заданные HTTPS-адреса магазинов. Пользовательские ссылки на сервере не открываются. Время проверки хранится вместе с предложением. Кэш источника — до 15 минут, CDN — 5 минут. При ошибке выбранная цена не стирается. Цены старше суток помечаются как старые.

Mtech: первая страница каждой из восьми категорий (обычно до 18 товаров). iSpace: доступные страницы iPhone 15, 16, 17 и 16 Pro. Это ограниченный каталог, не поиск по всему рынку и не гарантия минимальной цены. При изменении вёрстки магазина адаптер может потребовать обновления. Наличие Mtech по списку не определяется и помечается «уточняйте»; iSpace определяется по кнопке покупки. Конечную цену, наличие, доставку и гарантию проверяйте по прямой ссылке на магазин.

Нет выдуманных актуальных цен, оценки FPS, автоматической проверки совместимости и пересчёта валют. Демонстрационные устройства обозначены как пример. Новые проекты создаются пустыми.

## Сохранение и приватность

Проекты остаются в браузере пользователя и не записываются на сервер. Перезагрузка не сбрасывает данные. Очистка данных сайта, другой браузер или приватный режим могут привести к потере доступа — для переноса используйте JSON. Импорт добавляет копии, проверяет формат, размер и ссылки. Повреждённое сохранение не перезаписывается автоматически.

Цены запрашиваются по категории без содержимого проекта. Изображения каталога и шрифт загружаются с внешних публичных адресов. В ссылку общего доступа попадают названия, заметки, бюджет и цены конкретного проекта; не помещайте туда секреты. Ссылка передаёт снимок, изменения после отправки не синхронизируются.

## Деплой

Подключите репозиторий к Vercel: framework `Vite`, Node.js 24, `npm run build`, output `dist`. `/api/catalog.ts` публикуется как функция Node.js. Переменные окружения не требуются. `vercel.json` содержит настройки функции и защитные заголовки.

Для работы с деплоем рекомендуется CLI:

```powershell
npm i -g vercel
```

## Структура

- `src/components` — сравнение, бюджет, каталог и диалоги.
- `src/lib` — типы, проверка импорта и локальное хранение.
- `server/catalog.ts` — адаптеры магазинов, кэш и API.
- `api/catalog.ts` — точка входа Vercel.
- `tests` — проверка данных, обработки цен и пользовательских сценариев.
